# ВК-бот для подбора рецептов

Учебный проект ВК-бота, который подбирает рецепты по имеющимся продуктам
и предлагает варианты с небольшим списком покупок.

Сейчас в репозитории первый этап проекта: набор примеров и скрипт для
оценки модели. Скрипт показывает, как Gemma разбирает русскоязычные запросы
и выделяет продукты, исключения и условия покупки. Дальше Python будет
использовать эти поля для поиска рецептов. Рейтинг, шаги и фото будет
предоставлять источник рецепта.

В качестве первой модели выбрали [Gemma 4 E2B](https://ollama.com/library/gemma4:e2b-it-q4_K_M).
Запуск через Ollama сократит настройку, а для будущего дообучения можно
начать с [QLoRA](https://gemma.ai/tuning/qlora/).

## Первый запуск

Команды выполняются из папки `vk-recipe-bot`. Проверка набора работает
на стандартном Python.

```sh
python3 benchmark.py --validate-data
```

Для замера нужен запущенный [Ollama](https://docs.ollama.com/linux) на
`127.0.0.1:11434`. Если Ollama установлен без службы, запусти
`ollama serve` в отдельном терминале.

```sh
ollama pull gemma4:e2b-it-q4_K_M
ollama list
python3 benchmark.py --model gemma4:e2b-it-q4_K_M > baseline.txt
cat baseline.txt
```

Сохрани ID модели из `ollama list` вместе с результатом. Скрипт показывает,
на каких запросах и полях Gemma ошиблась, и считает долю полностью правильных
разборов. Для сравнения после дообучения пригодятся тот же набор, запрос к
модели, настройки генерации и способ квантования. Обучающие примеры готовим
отдельно от `eval.jsonl` и его перефразировок. Набор из 24 запросов нужен
для первого замера. Для более уверенного сравнения стоит расширить
независимую проверку.

## Что проверяем

| Поле | Что извлекаем |
| --- | --- |
| `ingredients` | Продукты, которые уже есть |
| `excluded` | Продукты и группы продуктов, которые нужно исключить |
| `can_buy` | Явно разрешённый список покупок, `[]` при запрете покупок, `null` без ограничений на список |
| `max_extra` | Явно заданный максимум недостающих продуктов, `0` при запрете покупок, `null` без лимита |

В запросе «Есть рис и курица. Без грибов, могу докупить только лук»
должны выделиться рис и курица, исключение «гриб» и разрешение докупить лук.
Числовой лимит в этом примере остаётся `null`, список покупок уже ограничен
луком. В списках порядок, регистр и разница между «е» и «ё» на оценку не влияют.

Следом за первым замером разберём ошибки и соберём примеры для дообучения.
Поиск рецептов и обработчик сообщений ВК будут использовать тот же формат запроса.
