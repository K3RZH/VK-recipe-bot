# ВК-бот для подбора рецептов

Учебный проект ВК-бота, который подбирает рецепты по имеющимся продуктам
и предлагает варианты с небольшим списком покупок.

Gemma определяет, хочет ли человек приготовить конкретное блюдо или найти
рецепт по запасам. Python ищет страницы в выдаче SearXNG, извлекает из них
рецепты и сверяет продукты. Карты FineCooking и 1000.menu дают дополнительные
варианты, в том числе когда SearXNG недоступен.
Чат предлагает рецепт без покупок и вариант с покупкой до двух продуктов,
если такие варианты найдены. Для ответов с сайтов выводится ссылка на
оригинал, оценка и число оценок или отзывов, если сайт их указал.
Вопрос «Хочу приготовить лосося. Что понадобится?» запускает поиск блюда
с полным списком продуктов. Ограничение в две покупки по-прежнему
действует, когда бот подбирает рецепт по имеющимся продуктам.

Если для блюда найден подходящий снимок из Wikimedia Commons, чат
показывает его как пример подачи, указывает автора и даёт ссылку
на файл и лицензию. Сайт Wikimedia получает названия публичных рецептов
или файлов, а не сообщения из чата.

`web_recipes.py` проверяет `robots.txt`, ищет кандидатов по названиям в
картах сайтов и читает не больше пяти страниц на источник за запрос.
Внешние запросы содержат публичные адреса страниц. Текст сообщения и список
продуктов используются локально. Gemma кратко пересказывает основные шаги
найденного рецепта. Если пересказ не прошёл проверку, чат оставляет ссылку
на пошаговую инструкцию. Локальные рецепты и учебная подборка из TheMealDB
остаются запасным вариантом.

## Обновить подборку TheMealDB

```sh
python3 themealdb.py
```

Скрипт загружает карточки из [официального API](https://www.themealdb.com/api.php)
по фиксированным ID и сохраняет их в `.recipe-cache/themealdb.json`.
Сообщения пользователей во внешний API не передаются. Русские шаги
сверены с конкретной версией оригинала. Если шаги изменились, импорт
останавливается и сохраняет прежнюю подборку. После импорта перезапусти сервер.
Учебный ключ рассчитан на разработку. Перед публичным релизом проверь
[условия TheMealDB](https://www.themealdb.com/terms_of_use.php).

В проекте используется [Gemma 4 E2B](https://ollama.com/library/gemma4:e2b-it-q4_K_M).

## Попробовать локально

Команды выполняются из папки `vk-recipe-bot`. Для демо нужен только Python.

```sh
python3 bot.py --demo
```

Демо использует готовый разбор запроса. Для своего сообщения запусти один
из локальных серверов ниже.

### Ollama

Запусти [Ollama](https://docs.ollama.com/linux) на `127.0.0.1:11434` и
скачай модель командой `ollama pull gemma4:e2b-it-q4_K_M`.

```sh
python3 bot.py --message "Есть рис, яйца, вода, соль и растительное масло. Докуплю только морковь."
```

### llama.cpp

Сервер [llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md)
тоже работает с Gemma 4 E2B. Укажи путь к уже скачанным весам в формате GGUF.

```sh
llama-server --model "$GGUF_PATH" --alias gemma4:e2b-it-q4_K_M \
  --host 127.0.0.1 --port 8080 --ctx-size 2048 --parallel 1 --n-gpu-layers all \
  --cors-origins localhost --no-webui
```

В другом терминале выбери этот сервер для бота и замера.

```sh
export RECIPE_MODEL_BACKEND=llama-cpp
python3 bot.py --message "Есть рис, яйца, вода, соль и растительное масло. Докуплю только морковь."
```

## Поиск по интернету

Запусти [SearXNG](https://docs.searxng.org/admin/installation.html) и добавь
`json` в `search.formats` его `settings.yml`. По умолчанию приложение ищет
SearXNG на `http://127.0.0.1:8888`. Для другого адреса задай `RECIPE_SEARX_URL`
в окружении `mini_app.py`, `bot.py` или `vk_bot.py`.

SearXNG отправляет запрос подключённым поисковым системам. В запрос идут
название блюда или названия имеющихся продуктов, выделенные моделью.
Чтобы проверить свой экземпляр, выполни:

```sh
curl -fsSG http://127.0.0.1:8888/search \
  --data-urlencode 'q=лосось в духовке рецепт' \
  --data-urlencode 'language=ru-RU' --data-urlencode 'format=json'
```

Приложение проверяет результаты с нескольких сайтов на запрос и читает
страницы с разметкой [Schema.org Recipe](https://schema.org/Recipe), если
доступ к ним допускается в `robots.txt`. Покрытие зависит от выдачи
подключённых поисковых систем и разметки сайтов. Подробности есть в
[описании API SearXNG](https://docs.searxng.org/dev/search_api.html).

## Подключить ВК

### Mini App

Мини-приложение открывает чат по ссылке `vk.com/app<ID>`. Для разработки
подними Gemma в одном терминале (на этом компьютере есть скрипт
`bash .ollama-local/start-model.sh`) и запусти сервер из корня проекта
в другом терминале.

```sh
RECIPE_MODEL_BACKEND=llama-cpp python3 mini_app.py
```

Чат доступен на `http://localhost:8765/`. В режиме разработки ВК нужен
HTTPS. Для настройки на этом компьютере создай локальный сертификат
или используй уже подготовленную пару файлов из `.miniapp-local`.

```sh
mkdir -p .miniapp-local
(umask 077; openssl req -x509 -newkey rsa:2048 -sha256 -nodes -days 365 \
  -subj /CN=localhost -addext 'subjectAltName=DNS:localhost,IP:127.0.0.1' \
  -keyout .miniapp-local/localhost.key -out .miniapp-local/localhost.crt)
RECIPE_MODEL_BACKEND=llama-cpp python3 mini_app.py \
  --cert .miniapp-local/localhost.crt --key .miniapp-local/localhost.key
```

Открой `https://localhost:8765/` в браузере на этом компьютере. Браузер
может попросить подтвердить исключение для самоподписанного сертификата.
В кабинете VK Mini Apps открой «Размещение», включи режим разработки и
укажи `https://localhost:8765/` как URL для веб-версии. Затем открой
страницу приложения `vk.com/app<ID>` в этом же браузере. Если Chrome
запросит разрешение на доступ к локальной сети для ВК, оно понадобится
для открытия чата с `localhost`.
[Руководство ВК](https://habr.com/ru/companies/vk/articles/771772/),
[документация Chrome](https://developer.chrome.com/docs/modern-web-guidance/guides/security/local-network-access).

Оба локальных сервера слушают только этот компьютер. Для теста с другого
устройства понадобится отдельное размещение по HTTPS. Ключ приложения в
интерфейс передавать не нужно. В комплекте есть браузерная сборка
[`@vkontakte/vk-bridge@2.15.0`](https://www.npmjs.com/package/@vkontakte/vk-bridge/v/2.15.0)
для `VKWebAppInit`.

Стили лежат в `miniapp/styles`. После правок пересобери CSS командой
`sass --no-source-map miniapp/styles/style.scss miniapp/style.css`
и перезапусти сервер.

### Личные сообщения сообщества

`vk_bot.py` принимает запросы прямо в личных сообщениях сообщества. Бот
использует ту же Gemma и интернет-поиск, что и Mini App. Он отправляет
рецепт со ссылкой на источник и прикрепляет фото, когда его удаётся найти
и загрузить в VK. Для этого режима сервер `mini_app.py` не требуется.

В сообществе включи сообщения. В разделе «Управление → Работа с API» создай
ключ сообщества с доступом к сообщениям и включи
[Bots Long Poll](https://dev.vk.com/ru/api/bots-long-poll/getting-started)
с событием «Входящие сообщения» (`message_new`).

Запусти локальную модель и SearXNG, затем выполни в терминале:

```bash
RECIPE_MODEL_BACKEND=llama-cpp python3 vk_bot.py --interactive
```

Скрипт примет ключ скрытым вводом. В поле ID можно нажать Enter, чтобы
узнать сообщество по ключу. Как только скрипт сообщит о подключении,
напиши сообществу «Хочу приготовить лосося в духовке».
С `--interactive --check` скрипт проверит только доступ к Bots Long Poll
и завершится. Для серверного запуска без интерактивного ввода доступны
переменные окружения `VK_GROUP_ID` и `VK_GROUP_TOKEN`.

В чате можно написать «Составь меню на неделю без рыбы», «Собери меню для
итальянского ресторана» или «Предложи меню для семейного ужина». Меню на
неделю включает завтрак, обед и ужин на каждый день. Меню ресторана разбито
на разделы. Кнопка «Покажи подробно №…» отправляет запрос на рецепт блюда
под этим номером. Бот выполнит поиск и пришлёт подходящий рецепт со ссылкой.
Сведения об авторе и лицензии прикреплённого фото доступны по отдельной кнопке.

## Замер качества Gemma

Первый скрипт замера проверяет извлечение продуктов и ограничений из
сообщений. Разбор типа запроса и названия блюда проверяет `train_router.py`.

```sh
python3 benchmark.py --validate-data
```

Для замера нужен один из локальных серверов выше. Список с ID модели
в Ollama можно посмотреть командой `ollama list`.

```sh
python3 benchmark.py --model gemma4:e2b-it-q4_K_M > baseline.txt
cat baseline.txt
```

Сохрани сервер и версию весов вместе с результатом. Скрипт показывает,
на каких запросах и полях Gemma ошиблась, и считает долю полностью правильных
разборов. Для сравнения после дообучения пригодятся тот же набор, сервер,
запрос к модели, настройки генерации и способ квантования. Обучающие примеры готовим
отдельно от `eval.jsonl` и его перефразировок. Набор из 24 запросов нужен
для первого замера. Для более уверенного сравнения стоит расширить
независимую проверку.

Первый замер на Gemma 4 E2B с llama.cpp b12728 дал 1 из 24 полностью
верных разборов. После уточнения инструкции модель разобрала 6 из 24
полностью верно. Правильный JSON получился во всех 24 случаях. В первую
очередь нужно улучшить выделение имеющихся продуктов и исключений.

## Что проверяем

| Поле | Что извлекаем |
| --- | --- |
| `ingredients` | Продукты, которые уже есть |
| `excluded` | Продукты и группы продуктов, которые нужно исключить |
| `can_buy` | Явно разрешённый список покупок, `[]` при запрете покупок, `null` без ограничений на список |
| `max_extra` | Явно заданный максимум недостающих продуктов, `0` при запрете покупок, `null` без лимита |

В запросе «Есть рис и курица. Без грибов, могу докупить только лук»
должны выделиться рис и курица, исключение «гриб» и разрешение докупить лук.
Числовой лимит в этом примере остаётся `null`, список покупок уже ограничен
луком. В списках порядок, регистр и разница между «е» и «ё» на оценку не влияют.

## Локальное дообучение

`train_router.py` обучает QLoRA-адаптер Gemma для разбора запроса. Примеры
в `router_data.py` включают опечатки, списки запасов, просьбы о конкретном
блюде, ограничения и сообщения на другие темы. Разметку и разделение
выборок можно проверить без GPU командой `python3 train_router.py --validate-data`.

Для обучения нужен Python 3.12, NVIDIA GPU с поддержкой BF16 и сборка
PyTorch для установленного CUDA-драйвера. Нужные версии PyTorch можно
выбрать в [инструкции по установке](https://pytorch.org/get-started/locally/).

```sh
python3.12 -m venv .training/venv
source .training/venv/bin/activate
# Сначала установи CUDA-сборку PyTorch по инструкции выше.
pip install 'transformers>=5.5,<6' 'peft>=0.18,<1' 'bitsandbytes>=0.49,<1' 'accelerate>=1.10,<2'
HF_HOME="$PWD/.training/hf" python train_router.py --seconds 3600 --compare
```

Эта команда скачивает исходные веса Gemma. Отсчёт часа начинается после
загрузки модели и первого замера. Адаптер сохраняется в `.training/run/adapter`,
результат сравнения печатается в терминал. Повторный запуск требует нового
каталога через `--output`. Загрузка адаптера в Mini App выполняется отдельно
после оценки качества.
[Руководство Gemma по QLoRA](https://gemma.ai/tuning/qlora/).
